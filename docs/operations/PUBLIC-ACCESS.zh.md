# 自行部署后的公网访问

本页使用文档示例IP 203.0.113.10和示例名称，不是可用的工作台入口。原维护者的真实访问地址由其私下提供。

## 配置域名

1. 使用自己管理的域名。可自行在 [DuckDNS](https://www.duckdns.org/) 申请免费子域名；账号登录和授权由本人完成，不向他人发送账号令牌。
2. 把域名的A记录指向自己的服务器公网IP。不要直接复制本页示例IP，也不要误用家庭网络IP。
3. 按服务器所在地和云平台要求完成域名接入手续。免费子域名不保证满足中国大陆服务器的备案条件，使用前向服务商核实。
4. 在Caddy配置实际地址和可信HTTPS证书，同时把服务端 `CC_ORIGIN` 设置为同一个HTTPS访问地址。
5. 使用移动网络测试登录、任务清单和使用说明，验证成功后再分发地址。

DuckDNS提供子域名及解析服务；仅修改DNS不表示服务器已经支持该域名。[官方介绍](https://www.duckdns.org/about.jsp)、[更新接口](https://www.duckdns.org/spec.jsp)。

## 访问保护

工作台密码、DNS更新令牌和模型密钥放在仓库外，使用独立的强密码。保持Origin校验及Secure/HttpOnly/SameSite会话保护；不要通过关闭证书校验解决访问问题。配置和切换前先备份，保留可回退的原版本。
