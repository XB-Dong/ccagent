# cc 工作台使用说明

当前是内部验收版。云端通过本机 SSH 加密入口 `http://127.0.0.1:4314` 访问；不是已验收的公网 HTTPS。访问密码保存在本机受限配置，由维护者提供，不写入项目。只使用合成数据，取得公司资料上传/发模型许可后再接真实数据。

打开先看到问候、任务和到期活动提醒。活动提醒在页面内显示，前台每30秒同步；不发送微信、邮件或手机推送。模型离线或额度用完时，记录、计算、任务和已有经验仍可使用。

## 助手与经验

可说“帮我整理美站活动准备清单，站点时区是America/Los_Angeles”“这个页面不好用，希望增加筛选”“记住：活动准备提前量是6小时”。助手创建内部草稿后在任务清单确认；仅说完成不会替代实际检查。可以停止当前回复，已保存的记录仍保留。

反馈页面可以补充、纠正、撤回和确认需求归类；导出为带日期、来源与稳定changeId的审阅包，产品不会自动改源码或推送GitHub。记忆中的确认事实与推断分开；纠正保留替代关系。任务逐项完成并明确确认成功后，低风险清单会生成经验；不适用可立即停用。长对话压缩由Harness处理，业务事实不因摘要截短丢失。关闭自动学习后基础操作仍正常。

## 活动与数据

活动填写店铺、链接、IANA时区和含偏移的完整时刻，例如 `2026-10-26T10:00:00-07:00`。服务端核对夏令时，当前活动须大于15分钟以容纳开始后检查。准备提前4小时是可改经验，不是平台通则。四阶段任务自动生成；生效/恢复由你到平台核实后记录，工作台不改价格或优惠。

数据报表先选销量或广告，填写店铺、站点、截至日期，上传或粘贴≤100KB/1000行CSV。先核对规范列映射与预览，再确认导入。可填入内置合成示例熟悉流程。日期/关键值缺失、负数、重复记录或坏引号会拒绝；不会当成0。广告如需广告组维度，额外映射 `adGroup`。通用Excel与自动报表API尚未接入。

## 库存与发货

预测默认需要截至日期连续7日销量；不足时明确填写人工日需求与原因。每次保存新意图生成版本，保留原均值和修正。页面提示距数据日期≥7天需要更新，当前不自动抓取每周报表。

库存输入的是已经排除预留的可售量；预留只展示。在途按实际预计日期填写，延误后要更新日期，不能保留过去日期假装未来到货。提前期、活动倍率、安全天数都作为明确假设保存。按日结果列出缺货与损失需求；补货建议是覆盖期最大缺口，提前期内缺口需人工核实加急/调拨，普通补货不能追回已损失销量。

同一批实物用同一物理批次编号登记一个共享池，给每店填写可用日期窗。为库存方案确认内部预留后生成发货草稿，共用字段可导出CSV；它不是未经核实的官方导入模板。检查保修卡、标签、认领和权限，填写目的仓、负责人及人工创建的Amazon/ERP单号，再记录发运和累计到货。部分到货不能为0或超量，运输中不允许取消并错误返还共享库存。

## 广告

选择广告批次及维度，按实际报表填写归因窗口、点击阈值和人工ACOS目标。链接/搜索词为跨活动同币种汇总；广告组保留活动归属。每日预算比较必须指定单个活动与预算币种。零分母显示“—”，未成熟归因只提示更新观察；成本未明确完整或币种不一致时利润未知。金额最多6位小数，超精度/安全范围拒绝。

建议是人工检查依据，不会自动调预算、出价或否词。模型调用与这些确定性计算分开；当前研发验收限额仍受全局预算保护，工具循环/压缩也计数，不能把剩余请求数当剩余对话条数。日常额度由维护配置明确设置，不自动追加研发预算。
