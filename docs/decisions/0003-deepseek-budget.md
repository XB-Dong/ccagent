# ADR 0003 · 测试等工作节约 DeepSeek 额度

日期：2026-10-26｜状态：用户明确追加的工程约束

## 来源与变化

用户追加：“测试等工作要节约 deepseek api 使用额度。追加到你觉得应该放的地方”。原计划已有有限重试和用量记录，但没有明确普通 CI/回归默认离线、共享预算及证据复用要求。

## 决定

将此要求写入 AI Coding 宪法、Agent 规则、P0 计划、验收与相关任务包，由[统一额度策略](../testing/deepseek-budget.md)定义细节。它属于研发成本约束，不增加到 cc 的业务需求总览或业务日期变更中。

普通测试使用确定性计算、合成夹具、故障注入和脱敏回放；必要的真实 API 验收采用少量代表样本，设置共享调用/token上限，计入循环、学习和失败重试；复用有效证据，按变化定向复验。数值预算未指定，付费验证在设置上限前保持关闭。

## 影响与边界

保留现有真实模型验收门槛，不为节约伪造结果。本次仅更新文档并运行仓库检查，不安装依赖、不调用 DeepSeek、不部署。预算拦截和记账在后续 P0 Foundation 中实现验证。
