## 模型额度的跨项验收约束

按[DeepSeek 额度策略](../docs/testing/deepseek-budget.md)执行，不增设一组需付费的预算测试：用计数 fake transport 验证默认不联网、未配置预算不启用付费测试、达到请求/token 上限在发送前拦截、并发共享额度、循环/重试计数和缺失 usage 保守记账。普通 CI 不配置真实 Key；没有 Key 时离线用例仍可运行。

P0-HARNESS 及必要模型提取质量抽样保留少量真实调用证据，记录版本、输入范围、调用数、token、失败与剩余预算；模拟超时/429等边界优先用故障注入，不主动用真实 API 制造错误。P0 的其他规则、持久化、范围、权限、恢复和大部分 UI/E2E 使用确定性夹具或脱敏回放，结果明确标注验证层级。

复用证据必须满足模型/参数、提示/工具契约、输入、范围和相关代码版本有效；变化只触发受影响的真实验收。节约不能把未运行项改成通过。以上预算控制当前仅为规格，尚未实现或验收。

最终范围与数据访问政策在 P0 启动前确认。某项未通过不能凭单测或页面可访问宣称 P0 completed；具体计划改动写新决定，不能运行后悄悄降门槛。
