## 先计划，再多 Agent 开发

每波按 P0 结构生成并由 Leader 自审冻结：目标/非目标、来源与需求 ID、精确基准 SHA、版本化规格/契约、依赖与风险、自包含任务包、验收矩阵、状态与进入决定。任务包包含根任务、允许路径/单写所有者、输入输出、验收命令、修复次数/停止条件和交付格式。未冻结不能派发代码任务，不预填并不存在的执行者、测试或审核结果。

Leader 管共享契约、范围、集成及发布决定；开发 Agent 分配有实质工作的实现任务；独立只读审核 Agent 检查需求、代码和验收缺口，Leader 逐项采纳/拒绝/暂缓并复验。并发写入必须独立分支/worktree 隔离，依赖任务顺序执行，按实际可用槽位工作，不照搬旧项目的模型分配、凭据或额度。首次派发前说明分工，无需再次询问授权。审核不能只在最终阶段进行，作者自查不能称独立审核。
