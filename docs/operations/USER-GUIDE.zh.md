# cc 工作台使用说明

## 第一次打开

打开维护者给你的工作台地址，输入密码，点“进入工作台”。左侧选功能；手机上先点左上角菜单。

## 先试这三件事

1. 记任务：点“任务清单”→“新建任务”，填写名称、时区和检查事项，点“确认并保存”。做完后逐项勾选，再确认完成。
2. 提建议：点“改进反馈”，写下哪里不好用、希望怎么改，点“记下这条建议”。以后可以补充或撤回。
3. 记习惯：点“经验与记忆”→“业务记忆”→“记住一件事”，例如“美站活动提前6小时准备”，确认后保存。

## 想让助手帮忙

点“运营助手”，输入“帮我整理明天活动的准备清单”，按回车或点发送。请说清店铺、站点和时间；助手拟好后，到“任务清单”检查并确认。
如果提示“助手暂时无法回复”，联系工作台维护者；任务、反馈等页面仍可使用。

## 其他功能，需要时再用

活动日历：安排活动，按准备、切换、检查、恢复的步骤跟进。提醒只在工作台里显示，不会发微信。
数据报表：点“填入示例”先练习，再检查、预览和确认导入。表格文件需另存为 .csv；按页面填写各项对应的报表列名。
库存补货：先填销量预测，再填可售库存、在途和运输天数，查看缺货时间与补货建议。
发货协同：记录共享库存、分配数量，检查发货准备事项，并填写亚马逊和公司系统的单号。
广告分析：选择已导入的广告报表，填写目标，查看分析建议。

## 记住这几件事

工作台不会替你在亚马逊或公司系统建单、改价、调整广告；这些操作仍需你完成。
先用示例数据熟悉流程；公司资料确认允许上传后再使用，不要填写账号密码等私密信息。
自动整理的经验可在“经验与记忆”查看；不适用就停用。暂时不想记录新反馈和习惯，可到“工作台设置”暂停自动学习。
用完后，到“工作台设置”点“退出登录”。
