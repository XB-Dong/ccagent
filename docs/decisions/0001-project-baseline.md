# ADR 0001 · 项目基线与当前授权

日期：2026-10-26｜状态：用户方向已确认，实施细节为提案

## 原选择与变化

旧交接的简单网页/Python 技术栈与先做活动的排序均未定稿。用户本轮明确本地目录 `D:/project/ccagent`、在 XB-Dong 新建私密仓库，并指定官方 DeepSeek Harness 与自适应沉淀目标。

## 决定

1. 新仓库名采用与目录一致的 `ccagent`；private=true。采用单仓库，不复制旧业务系统源码。
2. 本轮完成 P0 前置：文档、规范、上游调研、任务草案、检查和仓库发布。不启动产品开发或服务器部署。
3. 工程流程参考 classroom-annotator 和 AI Coding 范式；旧项目技术栈、模型、截止、授权和凭据不继承。
4. 提案以 Harness 插件/profile 扩展为主；Node/TypeScript 与上游保持一致，SQLite 业务存储、UI seam 和产物方式在 R0 验证。

## 后果

P0 提案优先底座与自适应最小闭环，完整库存/活动/发货/广告能力在业务文档保留。用户可按试用反馈调整波次；尚未完成的能力显式标记规划中。
