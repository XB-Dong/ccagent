# Learning

`Capture` persists user sources and bounded outbox jobs. `Learning` manages precise feedback merging, confirmed/inferred facts, rebuildable summaries and validated workflow skills. `export` versions confirmed requirement changes and creates review packages outside Git. Derived content never edits development instructions or grants business permissions.

Tests: `tests/learning.test.ts`, `privacy-closure.test.ts`, `tasks.test.ts`. The source records and structured facts remain authoritative; a display summary is not a replacement.
