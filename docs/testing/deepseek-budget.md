# DeepSeek API 额度节约策略

版本：0.1.0｜追加日期：2026-10-26｜状态：工程约束已确认，预算数值待执行时配置

来源：用户明确要求“测试等工作要节约 deepseek api 使用额度”。本文件约束研发与验证成本，独立于 cc 的业务需求。当前只有策略文档，预算拦截器和自动记账尚未实现。

## 默认离线，真实调用有界

| 工作 | 默认方式 | 何时需要真实 DeepSeek |
| --- | --- | --- |
| 文档、静态检查、构建、确定性业务规则 | 本地工具和规则计算 | 不需要 |
| 单元/契约/状态/权限/幂等/恢复测试 | 合成数据、stub/mock、fake transport | 不需要逐例调用 |
| UI/E2E、压缩/学习流程回归 | 固定响应或脱敏回放 | 仅补齐必要的真实模型闭环 |
| 超时、429、取消、异常格式等失败路径 | 故障注入 | 不主动烧额度制造错误 |
| 模型/协议/工具兼容性、提取质量 | 小规模代表样本 | 首次接入及相关变更后按需抽验 |
| 排障、审核和反复修复 | 先读证据、定位根因、离线复现 | 有明确尚未覆盖的问题再做定向探针 |

普通本地检查和 CI 默认不联网调用模型，不加载已有私密 Key。付费测试独立入口显式启用，并且处于已授权的波次范围；不能因环境里恰有 Key 就自动运行。当前前置文档工作不调用 DeepSeek。

## 执行前配置与调用前拦截

在 wave state / 任务包配置 `maxCalls / maxInputTokens / maxOutputTokens / maxTotalTokens / timeout / maxRetries`；费用上限可补充，但费率未经核实不编造金额。用户未指定具体额度，不在本次文档中虚填数字；开始付费验证前必须给出明确数值，未配置则保持关闭。

全部研发任务共享同一波次预算，任务可分配更小子预算，不能每个 Agent 各用一份全额。请求次数包括每个实际发送的模型请求、工具后续轮次、摘要/学习、重试和失败尝试；任务重命名、进程重启不清零。

调用前原子预留一次请求与预计输入/最大输出 token；预算不足或上下文过大先阻断，不发请求。并发调用共用持久账本。完成后按返回 usage 结算；超时、取消或缺少 usage 按保守预留记账并标 unknown，不当成零，也不声称它就是供应商最终计费。发出过的请求不能因本地失败而退还请求计数。

达到上限停止新的付费调用，保留已完成结果和未验证清单。独立离线工作可继续；不得自动充值、换 Key 绕额度、扩大预算或降低验收门槛。已授权额度内不逐次打断用户请求批准。

## 减少重复与无效输入

- 探针前先检查配置、网络、输入 schema 和模型响应处理；用最小合成材料，限制输入、输出及工具循环长度。
- 相同来源的学习任务幂等去重，批量整理新增内容，避免每条微小变化都全量总结；关闭没有变化的后台轮询调用。
- Foundation 与 Acceptance 共享已记录的实际调用证据；独立验收核查证据与行为，不为角色不同机械重复请求。未覆盖的必要场景仍需独立验证。
- 复用/回放按模型/参数、提示及工具契约哈希、输入/范围、相关代码和上游版本判定有效；有变化只重验受影响部分。不把旧响应缓存当作新版本实际调用。
- 回放只用合成或获准脱敏内容；不记录 Key、Cookie、客户信息或模型内部推理全文。缓存有范围、有效期与撤销传播，不因省额度复活已删除数据。

## 记录与诚实验收

每次真实调用记录目的、波次/任务、版本、起止时间、尝试/重试数、输入/输出/总 token（可用时）、usage 核实状态、剩余预算和结果。只记录必要 metadata，不额外调用模型总结测试日志或反复自评质量。

预算控制用 fake transport 测试，不能为了验证“节约额度”大量调用真实 API。保留必要的真实模型兼容性与最终闭环门槛；离线测试、脱敏回放、真实调用三者分别标注。预算不足时如实报告未验/部分完成，不把模拟结果包装成真实通过。
