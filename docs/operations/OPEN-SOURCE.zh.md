# 公开维护说明

2026-10-28，原维护者授权公开仓库隐私清理，并为原创部分采用 MIT 许可证。包的 private 标志用于防止意外发布到包注册表，不表示 GitHub 仓库私有。

## 示例与真实运维分开

公开文件中的 203.0.113.10 属于文档示例地址，域名和服务器目录也仅作部署示例。实际访问入口、凭据、数据、私有反馈关联和原始证据由维护者在仓库外保管。历史验收结论保留；替换示例配置不表示生产环境已经更改。

本机可通过 local-only Git 配置指定私有运维索引与反馈去重状态：

```sh
git config --local ccagent.operationsIndex /path/to/private/LOCAL-OPERATIONS.md
git config --local ccagent.feedbackState /path/to/private/feedback-state.json
```

自动维护先读取这两项；真实反馈的 ID、精确修订时间、内容指纹和删除状态只更新私有登记。公开需求保留中性功能说明和匿名编号。公开波次编号与完成状态继续维护，不能因脱敏重复开发或复活已删除反馈。

## 历史清理与协作

本次清理覆盖公开分支的文件历史与个人提交邮箱，历史提交SHA和签名会变化。旧部署源码身份、原证据及旧新提交映射保留在维护者的私有备份；不把改写后的SHA冒充已经部署过的版本。

已有克隆应重新克隆或由维护者按私有映射迁移，避免合并或推送清理前的分支。公开版本不附带原始业务资料。GitHub已关闭PR的内部引用、旧提交缓存及第三方已有副本可能仍保留历史内容；是否清除平台缓存须由平台处理，不能把分支更新称为全网删除。

## 防止再次公开私人资料

提交前运行 `python scripts/verify.py` 和 `python scripts/verify_public.py`。CI执行相同检查，阻止真实外网IP、个人绝对路径、生产反馈登记和常见凭据格式进入公开文件。提交与本地合并使用 GitHub no-reply 邮箱；平台代为创建合并提交时还应检查账号邮箱隐私设置。

第三方依赖保留各自许可及来源；本次清理不扩大真实数据、模型调用、云发布或外部业务操作权限。
