# 给 CC 使用公网工作台

## 现在直接用

打开 **https://203.0.113.10/**，输入已有工作台密码即可。电脑、手机都使用这个地址，不需要连接原来的本地隧道。密码不放在这份说明里。

公网HTTPS及密码登录已通过外部请求验证。助手的调用上限是另一项设置，目前仍需处理；任务、反馈、经验和报表等页面可以继续使用。

## 想先申请免费域名

1. 打开 [DuckDNS](https://www.duckdns.org/)，使用你自己的账号登录；首次出现授权或条款时由你核对并完成。
2. 在域名区域输入想要的名字，例如 `cc-demo`，点 **add domain（添加域名）**。名字被占用就换一个；成功后会得到类似 `cc-demo.duckdns.org` 的地址。
3. 找到这条域名的 **current ip（当前IP）**，填写 **203.0.113.10**，点 **update ip（更新IP）**。不要保留网页登录时自动填入的家庭网络IP。
4. 把成功创建的完整域名发给维护者即可；不要发送页面上的账号令牌。维护者继续检查解析、配置域名HTTPS和工作台地址，再用手机网络验证登录。

这里的域名只是举例，尚未注册成功。DuckDNS提供的是免费子域名，不是你独立持有的根域名；只更新IP并不等于服务器已经支持该域名。[官方说明](https://www.duckdns.org/about.jsp)、[解析更新说明](https://www.duckdns.org/spec.jsp)。

## 如果准备长期正式使用

当前服务器位于广州。域名接入需按京东云及主管部门要求办理相应手续，免费子域名不保证满足备案条件；IP能访问也不代表免备案。[主管部门说明](https://jxca.miit.gov.cn/bsfw/bszn/cjwt/art/2020/art_869445de6a9f40e98732195df440f99d.html)。

正式域名按这个顺序办理：

1. 在有资质的注册商选择独立域名，核对续费价格后自行购买并完成实名认证。
2. 在京东云控制台的备案入口，按实际主体和用途填写资料；身份证、人脸核验等由本人完成。可备案域名及注册主体要求以平台审核为准。
3. 在域名的“解析”里添加下面这条记录。

| 项目 | 填什么 |
| --- | --- |
| 记录类型 | A |
| 主机记录 | cc |
| 记录值 | 203.0.113.10 |
| 其他选项 | 保持默认 |

4. 把得到的 `cc.你的域名` 交给维护者，完成服务器的HTTPS和入口切换。实际域名验证通过前保留现有IP入口，不提前宣布域名可用。
5. 手机关闭无线网络，用移动网络打开域名并登录；确认“任务清单”和“使用说明”正常后，把域名发给CC收藏。

## 维护者接续事项

新增域名必须属于用户账号并已解析到此服务器；先检查云平台是否放行，再添加Caddy站点和可信证书。切换应用`CC_ORIGIN`到实际使用的HTTPS域名；旧IP入口在新入口验证后重定向到域名。不要把任意Origin放行、关闭Secure cookie，或让用户跳过证书警告。动态IP变更后才需要受限的DNS更新凭据，固定IP的初次接入不索取DuckDNS令牌。
