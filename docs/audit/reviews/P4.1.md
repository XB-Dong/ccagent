# P4.1 独立审核与处置

日期：2026-10-27｜审核执行者：/root/p41_review（只读）｜实现者：/root/p41_task、/root/p41_ui、/root/p41_notes；集成及处置：Leader。

审核覆盖冻结契约、领域/时间/旧数据、学习笔记、隐私重放、共享 API 和中文 UI。实际发现与修复如下，不把作者自查冒称独立审核。

| 级别/根因 | 触发与影响 | 处置与复验 |
| --- | --- | --- |
| P2 note-old-reader | 旧恢复器将不识别的 delete-note 标为 closure-v2 已处理，随后新读者跳过删除，恢复出旧笔记 | 接受；新事件专用 closure-v3-note 标记。Leader 保留实际 Red/Green；审核者使用精确旧源码复现由 remainingNotes=1 转为 0，两种标记共存。恢复必须采用新版工具 |
| P2 task-create-retry | 创建已落库但响应/刷新失败，表单保留；改内容再用固定 requestId 提交会返回旧内容并关闭 | 接受；内容确实变更才换请求编号，不变重试保留；提交时禁止继续改字段。独立审查所有输入及清除无变化路径 |
| P2 actual-minutes-revision | 编辑实际用时期间快照更新 revision，而表单保留旧值，提交时借新 revision 覆盖另一页修改 | 接受；固定打开编辑器时的 ID/revision；失败保留值，按乐观锁报告冲突。独立审查修复 |

此外 Leader 在集成时主动修正笔记通用删除会清理无关聊天的旧行为：只对 note 使用限定隐私事件，仍作闭包删除与恢复重放，不退休无关会话/摘要。该改动也纳入独立审核及恢复测试。

审核者实际运行相关 30 项离线测试、类型检查和差异检查，均通过，未发现剩余代码阻断。审核者没有执行完整套件、浏览器、真实模型、GitHub CI 或云发布；这些结果由 Leader 的实际后续证据单独记录。原始审核复现及各开发者 Red/Green 输出在仓库外 evidence/p41。
